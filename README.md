# SmartGrade Prototype AI Prompt Pack

## What this is
This folder is prepared for an AI coding/prototyping model that will generate the SmartGrade Round-2 prototype.

## Start here
1. Read `01_MASTER_PROMPT/SMARTGRADE_MASTER_PROMPT.md`.
2. Read both files in `03_REFERENCE_MATERIALS/`.
3. Add the final SmartGrade dataset under `02_DATASET_TO_ADD/`.
4. Use `04_IMPLEMENTATION_SPECS/` for the schema, visual theme and acceptance checklist.

## Reference materials
- SmartGrade_Final_System_Architecture_and_Prototype_Blueprint.docx
- Adobe Scan 27 Sept 2026.pdf

## Dataset
Put the validated dataset into `02_DATASET_TO_ADD/`.
The master prompt tells the AI model how to use it and what it must not invent.
